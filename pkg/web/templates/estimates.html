Daily estimates

How this is calculated

One row per day. Each day uses the most accurate reading (see Settings); days without readings are interpolated, and after the last reading the last value is held. The series is a centred 7-day rolling average. A DEXA value is used when there is one; otherwise the series is corrected by the offset to DEXA scans for the same method and mode (blended smoothly between two scans). Stored readings are never changed. Faded values are interpolated or held.
