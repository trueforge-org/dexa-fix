Running workers

Workers talk to Withings, Strength Level and the like for DexaFix: imports, syncs and connecting an account run in them, never in the server. Jobs wait in a queue until a worker takes them. Administrators' jobs go first, then users with a higher priority number (set on the users table), then the oldest.

All workers

A higher priority number goes first. Administrators' jobs always go before everyone else's, whatever the number. A user's own priority is set on the users table.

Queue

The latest {{len .Jobs}} jobs. A job that fails is tried again after a growing pause, up to the number of attempts above, and is then kept here as failed. A job nobody picks up in time is dropped, and one whose worker stops answering is taken back.
